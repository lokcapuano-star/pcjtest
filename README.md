# ⚡ Teste Interativo: Quem é o seu Parente Divino? (Percy Jackson)

Aplicativo web estático com cálculo automático de pontuação para descobrir seu parente divino no universo de Percy Jackson.

## Como publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Vá em **Settings > Pages**, selecione a branch `main` e a pasta `/ (root)` e clique em **Save**.
